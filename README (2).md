# Map data

Include a map in your trip planner. [OpenStreetMap](https://www.openstreetmap.org) is a source of map data; `city-maps.json` contains real Denver and Charlotte extracts you may use. Your team chooses the map design and interactions. The extracts contain compact vector paths, labels, projection metadata, bounds, source queries and timestamps. They are geographic snapshots, not a routing or travel-time service.

Source: © OpenStreetMap contributors, obtained through https://overpass-api.de/api/interpreter. Upstream snapshots are dated 2026-09-26 UTC. The adapted paths use Web Mercator in a 1000 × 650 coordinate space; details are in the JSON metadata. Coverage is limited to the supplied city areas.
