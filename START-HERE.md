# Meeting and Trip Itinerary Planner

Open this extracted folder in Codex and ask it to read SKILL.md. Start with the shared brief and bundled five-minute Grill, then explore local React prototypes.

Follow [the lab sequence](references/workshop-start.md), [the framework](references/project-framework.md), and [your project minimums](references/workshop-guide.md). Use the [team card](references/team-card.md) while you build.

The lab is two hours including preparation, followed by a 5–7 minute presentation. No plugin installation is needed; follow [ai-tooling access](references/ai-tooling-access.md).


Before the timed session, have Codex check the [local React preview](references/react-prototyping.md). Keep the source and reuse the selected approach for the Vibes build.

Ask Codex to keep a concise project log as you work. At the end, submit one team package through the hub: app link, editable three-slide presentation and reviewed log/feedback. All six questions go on the final slide; spend the live presentation showing your app.

## Ready to submit?

Ask Codex: **“Prepare my full project submission ZIP, including the app source and rebuild instructions, presentation, app link/version, and project log/feedback. Flag anything missing and show me the files to review.”** The files will be in `submission/`. Review them, then load the ZIP in your hub submission form. See [the packaging guide](references/submission-package.md).
